# IsHappyy — ระบบทำคลิปสั้นความรู้ด้วย AI

ให้ AI ส่งงานต่อกันเป็นสายพาน: **ค้นข้อมูล → เขียนบท → พากย์เสียง → ซับไทเทิล → ประกอบคลิป**

```
หัวข้อ ─▶ [Claude + ค้นเว็บ] ─▶ research.md
                │
                ▼
          [Claude เขียนบท] ─▶ script.json  ◀── 👀 คุณตรวจตรงนี้
                │
                ▼
          [ElevenLabs พากย์] ─▶ audio/voice_XX.mp3
                │
                ▼
          [สร้างซับจากบท] ─▶ subtitles.srt
                │
                ▼
          [ภาพ + FFmpeg ตัดต่อ] ─▶ final.mp4 + caption.txt
```

AI แต่ละตัวไม่ได้ "คุยกัน" เอง โปรแกรม `run.py` เป็นตัวกลาง เรียก AI ตัวแรก
เก็บผลลัพธ์ลงไฟล์ แล้วส่งไฟล์นั้นให้ AI ตัวถัดไป แต่ละขั้นมีไฟล์ผลลัพธ์ของตัวเอง
จึงตรวจและแก้ได้ทีละขั้น

## ติดตั้ง

ต้องมี Python 3.10+ และ [FFmpeg](https://ffmpeg.org/download.html)

```bash
pip install -r requirements.txt
cp .env.example .env      # แล้วใส่ API key ในไฟล์ .env
```

| Key | เอาจากไหน |
|---|---|
| `ANTHROPIC_API_KEY` | https://console.anthropic.com (ใช้ค้นข้อมูลและเขียนบท) |
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | https://elevenlabs.io (เลือกเสียงที่พูดไทยได้ แล้วคัดลอก Voice ID) |

## วิธีใช้

```bash
# 1) ขอไอเดียหัวข้อ
python run.py ideas สุขภาพ

# 2) ค้นข้อมูล + เขียนบท (หยุดรอให้คุณตรวจ)
python run.py new "นอนน้อยทำให้อ้วนจริงไหม"

# 3) เปิด projects/<โฟลเดอร์>/script.json อ่าน review_notes แก้บทได้ตามใจ
#    แล้วเอา prompt ใน images/prompts.txt ไปสร้างภาพ
#    บันทึกเป็น images/scene_01.png, scene_02.png, ...

# 4) พากย์ + ซับ + ตัดต่อ
python run.py render projects/<โฟลเดอร์>
```

ยังไม่มี key เสียงก็ลองได้ ใช้ `--voice silent` ระบบจะใส่เสียงเงียบแทนเพื่อทดสอบการตัดต่อ
ถ้ายังไม่มีภาพ ระบบจะใส่การ์ดสีพาสเทลแทนให้ก่อน

## ปรับแต่งช่อง

แก้ `channel.json` ได้ทั้งชื่อช่อง น้ำเสียงการเล่า หน้าตามาสคอต สไตล์ภาพ และประโยคปิดท้าย
คำบรรยายมาสคอตจะถูกใส่ในทุก prompt ภาพ ตัวละครจึงหน้าตาใกล้เคียงกันทุกคลิป

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `run.py` | คำสั่งหลัก และเป็นตัวส่งงานระหว่างขั้น |
| `shorts/claude.py` | เรียก Claude API (มี fallback อัตโนมัติ) |
| `shorts/research.py` | ขั้น 1: ค้นเว็บ เขียนบันทึกพร้อมแหล่งอ้างอิง |
| `shorts/script.py` | ขั้น 2: เขียนบทแยกฉากเป็น JSON |
| `shorts/voice.py` | ขั้น 3: พากย์เสียงทีละฉาก |
| `shorts/subtitles.py` | ขั้น 4: สร้าง .srt จากบท (ไม่ต้องถอดเสียง) |
| `shorts/visuals.py` | ขั้น 5: ภาพประจำฉาก + ไฟล์ prompt |
| `shorts/assemble.py` | ขั้น 6: FFmpeg ซูมภาพช้า ๆ + ต่อคลิป + ฝังซับ |

อยากเปลี่ยนผู้ให้บริการเสียง เช่น Botnoi ให้เพิ่มฟังก์ชันใน `shorts/voice.py` แล้วลงทะเบียนใน `PROVIDERS`

## ⚠️ ก่อนโพสต์ทุกครั้ง

- อ่าน `review_notes` และเปิดลิงก์ใน `sources` ตรวจข้อเท็จจริงเอง โดยเฉพาะเรื่องสุขภาพ
- ติดป้าย "สร้างด้วย AI" ตอนอัปโหลดทั้งบน TikTok และ YouTube
- ห้ามใช้ฟุตเทจหรือโลโก้ของลีก/ทีมจริงในคลิปกีฬา
