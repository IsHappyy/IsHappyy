# บอร์ดงาน Jig / Fixture: เซิร์ฟเวอร์โรงงาน

ระบบติดตามงาน Jig แบบชุด + เส้นทางชิ้นส่วน ใช้ในวง Wi-Fi/LAN ของโรงงาน เปิดได้ทั้งคอมและมือถือ
แพ็กเกจนี้มี Node.js 24 (`node\node.exe`) มาให้แล้ว ใช้กับ Windows 10/11 แบบ 64 บิตได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม ข้อมูลเก็บในไฟล์ SQLite ในเครื่อง

## ติดตั้งบนเครื่องใหม่
1. แตกไฟล์ zip ไปไว้ในโฟลเดอร์ที่จะใช้ประจำ เช่น `D:\JigBoard` (อย่าเปิดใช้จากในไฟล์ zip และไม่ควรวางไว้ใน `C:\Program Files`)
2. ดับเบิลคลิก `start-server.bat` ถ้า Windows ถามเรื่องสิทธิ์เครือข่ายของ Node.js ให้ติ๊ก **Private networks** แล้วกด Allow
   - ถ้า Windows SmartScreen เตือนว่าไฟล์มาจากเครื่องอื่น ให้กด **More info → Run anyway**
3. เปิด `http://localhost:8080` แล้วเข้าระบบด้วยชื่อผู้ใช้และรหัสเดิมที่ใช้อยู่ ข้อมูลงาน ผู้ใช้ และไฟล์สำรองย้ายมาครบแล้ว
4. ถ้ามือถือเข้าไม่ได้ ให้คลิกขวา `ตั้งค่า-firewall.bat` → **Run as administrator** (เปิดพอร์ต 8080 ให้เครือข่าย Private)
5. ลืมรหัส admin: ปิดเซิร์ฟเวอร์ แล้วดับเบิลคลิก `รีเซ็ตรหัส-admin.bat` รหัสใหม่จะอยู่ใน `data\password-admin.txt`
6. ทำขั้นตอน “ให้เครื่องนี้ทำงานเป็นเซิร์ฟเวอร์ได้ต่อเนื่อง” ด้านล่างบนเครื่องใหม่ด้วย

**สำคัญ:** หลังย้ายมาเครื่องใหม่แล้ว ให้ปิดเซิร์ฟเวอร์ที่เครื่องเก่า ถ้าเปิดสองเครื่องพร้อมกัน ข้อมูลจะแยกกันและไม่รวมกัน

## เปิดใช้งาน

1. ดับเบิลคลิก `start-server.bat` จะมีหน้าต่างดำเปิดค้างไว้ (ปิดหน้าต่าง = ปิดเซิร์ฟเวอร์)
2. ครั้งแรกที่เปิด Windows อาจถามว่าให้ Node.js เข้าถึงเครือข่ายไหม ให้ติ๊ก **Private networks** แล้วกด Allow
3. บนเครื่องนี้เปิด `http://localhost:8080`
4. มือถือและคอมเครื่องอื่นเปิดที่อยู่ที่หน้าต่างดำแสดง เช่น `http://192.168.1.41:8080` (ต้องต่อ Wi-Fi วงเดียวกัน)

### เข้าระบบครั้งแรก
- ชื่อผู้ใช้ `admin` รหัสผ่านชั่วคราวอยู่ในไฟล์ `data\password-admin.txt`
- เข้าแล้วกดชื่อมุมขวาบน → **เปลี่ยนรหัสผ่าน** แล้วลบไฟล์ `password-admin.txt` ทิ้ง

### เพิ่มพนักงาน
กดชื่อมุมขวาบน → **เพิ่มผู้ใช้** ระบบจะแสดงรหัสชั่วคราวครั้งเดียว ให้แจ้งพนักงานแล้วให้เปลี่ยนเอง

| ระดับ | ทำอะไรได้ |
|---|---|
| ดูอย่างเดียว | ดูทุกหน้า แก้ไม่ได้ |
| ใช้งาน | เปลี่ยนขั้นงาน กดเริ่ม/เสร็จ สั่งของ สร้างงาน (ช่างและฝ่ายวางแผนส่วนใหญ่ใช้ระดับนี้) |
| หัวหน้า (Editor) | ทุกอย่างข้างบน + กู้ข้อมูลจากไฟล์ Excel |
| ผู้ดูแลระบบ | ทุกอย่าง + จัดการผู้ใช้ |

ลืมรหัส admin: ปิดเซิร์ฟเวอร์ แล้วดับเบิลคลิก `รีเซ็ตรหัส-admin.bat`
รหัสใหม่จะถูกเขียนไว้ที่ `data\password-admin.txt`

## ใช้บนมือถือ
- เปิดที่อยู่ `http://<IP เครื่องนี้>:8080` ใน Chrome (Android) หรือ Safari (iPhone)
- เมนู ⋮ หรือปุ่มแชร์ → **เพิ่มลงในหน้าจอหลัก** จะได้ไอคอนบอร์ดงานไว้กดเปิดเหมือนแอป
- หน้างานใช้ **Kanban → ชิ้นส่วน** จะเห็นชิ้นที่รอแต่ละขั้น กด “เริ่ม…” หรือ “… เสร็จ” ได้เลย ระบบลงเวลาและชื่อคนกดให้เอง

## ให้เครื่องนี้ทำงานเป็นเซิร์ฟเวอร์ได้ต่อเนื่อง (ทำเองครั้งเดียว)
1. **ไม่ให้เครื่องหลับ:** Settings → System → Power → Screen and sleep → ตอนเสียบไฟ “Make my device sleep after” = **Never**
2. **ให้ IP ไม่เปลี่ยน:** เข้าหน้าตั้งค่า router แล้วจอง IP (DHCP reservation) ให้เครื่องนี้ ไม่อย่างนั้นที่อยู่ `192.168.x.x` อาจเปลี่ยนหลังรีสตาร์ต
3. **เปิดเองตอนเปิดเครื่อง:** กด `Win + R` พิมพ์ `shell:startup` แล้วคลิกขวาสร้าง Shortcut ไปที่ `start-server.bat`
4. **มือถือเข้าไม่ได้ทั้งที่ Wi-Fi เดียวกัน:** ส่วนใหญ่เป็นเพราะ Firewall หรือเครือข่ายถูกตั้งเป็น Public
   - Settings → Network & internet → Wi-Fi → เลือกวงที่ใช้ → Network profile type = **Private**
   - หรือเปิด PowerShell แบบ **Run as administrator** แล้วรัน
     `New-NetFirewallRule -DisplayName "Jig Board 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Private`

## สำรองและกู้ข้อมูล
- **อัตโนมัติ:** สำรองทุก 6 ชั่วโมงไปที่ `data\backups\` เก็บย้อนหลัง 30 ไฟล์
- **ทันที:** ดับเบิลคลิก `backup-now.bat`
- **แนะนำ:** ก็อปโฟลเดอร์ `data\backups\` ไปเก็บที่ NAS หรือไดรฟ์อื่นเป็นประจำ เผื่อเครื่องนี้เสีย
- **กู้จากไฟล์สำรอง:** ปิดเซิร์ฟเวอร์ → ลบ `data\jigboard.db`, `jigboard.db-wal`, `jigboard.db-shm` → ก็อปไฟล์จาก `data\backups\` มาวางเป็น `data\jigboard.db` → เปิดเซิร์ฟเวอร์ใหม่
- **ไฟล์ Excel:** ปุ่ม “สำรองข้อมูล” ในหน้าเว็บยังใช้ได้ เป็นสำเนาที่เปิดอ่านได้ และใช้ย้ายข้อมูลเข้าออกระบบ
  - ฟอนต์, ตัวสร้างไฟล์ Excel และตัวอ่าน PDF (`vendor\pdfjs\`, pdf.js 3.11.174) อยู่ใน `public\vendor\` แล้ว ใช้ได้แม้เครื่องในโรงงานไม่มีอินเทอร์เน็ต

## นำเข้ารายการสั่งจาก Misumi
- หน้า สั่งซื้อ / จ้างทำ → "นำเข้าจาก Misumi (PDF / CSV)…"
- **PDF:** ใบยืนยันการสั่งซื้อสินค้าของ Misumi ได้รหัส จำนวน และกำหนดรับ (วันในวงเล็บหลังวันส่ง) ให้เลย หมายเหตุใส่เลขที่ใบสั่งซื้อให้ แถวที่ Misumi ยกเลิก (ตัวแดง) ให้เอาติ๊กออกเองในหน้าตรวจ
- **CSV / Excel:** ต้องมีคอลัมน์รหัสสินค้า (`รหัส`, `Part`, `Product`, `Item`, `Model`, `Code`) และจำนวน (`จำนวน`, `Qty`, `Quantity`) ดูตัวอย่างใน `ตัวอย่าง-นำเข้า-Misumi.csv`
- รหัสที่ชุดนั้นสั่งไว้แล้วจะเริ่มแบบไม่ติ๊ก กันนำเข้าซ้ำ

## อัปเดตหน้าเว็บ / ย้อนกลับ
- หน้าเว็บคือไฟล์ใน `public\` (`index.html`, `app.css`, `vendor\`) เปลี่ยนไฟล์แล้วไม่ต้องปิดเซิร์ฟเวอร์ ให้ทุกคนกด Ctrl+F5 (มือถือกดรีเฟรช)
- ก่อนอัปเดตทุกครั้ง: กด `backup-now.bat` และก็อป `public\` เก็บไว้
- หน้าเว็บรุ่นก่อนหน้าเก็บไว้ที่ `public-old\` ถ้าหน้าใหม่มีปัญหา ให้ก็อปไฟล์ใน `public-old\` กลับไปทับ `public\` (ข้อมูลไม่หาย เพราะอยู่ใน `data\`)
- `public-old-before-orders-csv\` คือหน้าเว็บก่อนเพิ่มนำเข้า CSV / จำนวน / แก้ไขรายการสั่ง
- `public-old-before-scrollfix\` คือหน้าเว็บก่อนแก้ปัญหาเด้งกลับบนสุด
- `public-old-before-plating\` คือหน้าเว็บก่อนเพิ่มระบบส่งชุบ / งานนอก
- ถ้าแก้ `app.css` ให้เปลี่ยนเลข `app.css?v=` ใน `index.html` ด้วย ไม่อย่างนั้นเครื่องที่จำไฟล์เก่าไว้จะยังได้หน้าตาเดิมไปอีกประมาณ 1 ชั่วโมง
- `public-old-before-redesign\` คือหน้าเว็บรุ่นแรกก่อนปรับดีไซน์ เก็บไว้อ้างอิง
- ไฟล์สำรองด้วยมือ (`backup-now.bat`) ใช้ชื่อเดิมทั้งวัน กดซ้ำวันเดียวกันจะทับไฟล์เดิม ถ้าจะเก็บหลายจุดในวันเดียว ให้เปลี่ยนชื่อไฟล์ใน `data\backups\` ก่อนกดครั้งถัดไป

## โครงสร้างไฟล์
| ไฟล์ | คืออะไร |
|---|---|
| `server.mjs` | เซิร์ฟเวอร์ (หน้าเว็บ, API, ล็อกอิน, สำรองข้อมูล) |
| `public\index.html` | หน้าเว็บบอร์ดงาน |
| `data\jigboard.db` | ฐานข้อมูล **ห้ามลบ** |
| `data\backups\` | ไฟล์สำรองอัตโนมัติ |
| `import\` | ข้อมูลที่ดึงมาจากเวอร์ชันทดลองบน claude.ai (ใช้ตอนตั้งระบบครั้งแรก) |

ฐานข้อมูลเก็บประวัติการเขียนทุกครั้งไว้ในตาราง `history` (ใคร แก้อะไร เมื่อไหร่) ใช้ตรวจย้อนหลังหรือกู้เอกสารที่แก้ผิดได้

## ข้อจำกัดของเวอร์ชันนี้
- ใช้ HTTP ธรรมดาในวงแลน ไม่ควรเปิดให้เข้าจากอินเทอร์เน็ตตรง ๆ ถ้าต้องเข้าจากข้างนอกให้ใช้ VPN
- ถ้าสองคนแก้ช่องเดียวกันของงานเดียวกันพร้อมกันพอดี คนที่บันทึกทีหลังจะทับ (แก้คนละชิ้นส่วนไม่ทับกัน)
- เครื่องนี้ปิดหรือหลับ = ทุกคนใช้งานไม่ได้ ระยะยาวควรย้ายไปเครื่องที่เปิดตลอดเวลาหรือเซิร์ฟเวอร์ของ IT (ก็อปทั้งโฟลเดอร์ไปได้เลย)
